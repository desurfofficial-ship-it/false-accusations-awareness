# False Accusations Awareness

A simple educational website documenting high-profile, publicly verified cases of people who were **falsely accused of crimes**, the individuals who made false claims (or later admitted fabrication), and the broader support or rush-to-judgment that amplified the accusations.

**Purpose:** Help society remain cautious. False accusations destroy lives and also make it harder for genuine victims to be believed. Due process, evidence, and restraint matter.

## Live Site

Because this is a static HTML site, you can view it in two easy ways:

1. **GitHub Pages** (recommended)  
   Go to the repository **Settings → Pages**, set Source to `Deploy from a branch`, choose branch `main` and folder `/ (root)`, then save.  
   After a minute or two the site will be available at:  
   `https://desurfofficial-ship-it.github.io/false-accusations-awareness/`

2. **Open locally**  
   Clone the repo and open `index.html` in any browser.

## Cases Currently Featured

- **Duke Lacrosse (2006)** – Crystal Mangum later admitted she fabricated the rape allegations against three players.
- **Central Park Five / Exonerated Five (1989)** – Convictions vacated after DNA and the real perpetrator’s confession.
- **Scottsboro Boys (1931)** – Historic false rape accusations driven by racial prejudice; convictions eventually overturned/pardoned.
- **Steven Avery – First Conviction (1985)** – Exonerated by DNA after 18 years (this entry concerns only the 1985 case).

All information is drawn from public records, court outcomes, official statements, and widely reported admissions.
