About this registry

This registry page lists documented exonerations in a sortable, filterable table. Each entry includes the exoneree's name, year of conviction and exoneration, country (and US state where applicable), crime type, contributing factors, a one-sentence summary, and a link to a public primary source.

The full National Registry of Exonerations hosted by the University of Michigan Law School and University of California Irvine lists ~3,600 cases. That dataset is behind Cloudflare protection, which blocks automated ingestion. The cases shown here are a curated subset drawn from Innocence Project case lists, NRE annual reports, and major investigative reporting — every entry has a clear public-record source.

If you have downloaded the official NRE CSV and want to replace this subset with the full dataset, see scripts/convert_nre_csv.py in the GitHub repository — it converts the NRE CSV into the JSON format this page reads.
